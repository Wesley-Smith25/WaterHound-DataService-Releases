# WaterHound DataService Releases

Public distribution repository for packaged WaterHound DataService releases.
Application source code is maintained in private repositories. This repository
does not contain source code, credentials, customer data or private signing keys.

## Product features

WaterHound DataService combines a Vue website and .NET backend with PostgreSQL
and an HTTPS gateway. It supports account and site administration, device
registration and enrollment, authenticated heartbeat and alarm ingestion,
live alarm views, phone pairing and targeted alarm delivery, and signed device
firmware management. Customer-operated and WaterHound-operated installations
use the same application.

## Release availability

No installable public release has been published yet. The initial source
baseline is committed privately; remaining acceptance and distribution checks
must be completed before a packaged release is advertised here.

Future releases will include versioned installation artifacts, release notes,
integrity checks and upgrade instructions. Device firmware is a separate
artifact; this repository does not currently provide a public firmware source.
